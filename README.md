# Sistema di Gestione delle Spese Personali e del Budget

Applicazione console sviluppata in Python con database relazionale SQLite per il monitoraggio delle spese giornaliere, la gestione delle categorie, la definizione del budget mensile e la generazione di report.

## Struttura del Repository
- `src/main.py`: Codice sorgente principale dell'applicazione.
- `sql/database.sql`: Script SQL per la creazione dello schema, dei vincoli e dei dati di esempio.
- `demo/`: Cartella contenente la demo video del progetto.

## Requisiti per l'esecuzione
- Interprete Python 3.10 o superiore.
- Librerie utilizzate: Solo librerie standard integrate in Python (`sqlite3`, `datetime`). Non è richiesta l'installazione di pacchetti esterni.

## Istruzioni di avvio del programma
Aprire il terminale nella cartella principale del progetto ed eseguire il seguente comando:
```bash
python src/main.py
